# Сравнение Git и SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

**Git:** ветка — это просто указатель на коммит. Создаётся мгновенно, занимает байты, работает локально.

**SVN:** ветка — это физическая копия директории на сервере. Требует места и времени, работает только через сервер.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

**Нет.** SVN — централизованная система, все коммиты идут на сервер. Без сети коммит невозможен. Локально можно только редактировать файлы и смотреть diff.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

- **Legacy-проекты** (банки, госсектор) — миграция на Git слишком дорогая.
- **Простой линейный workflow** без веток и PR.
- **Гибкие права доступа** на уровне директорий (в SVN проще).
