# Git в VS Code: заметки

## 3 вещи, которые удобны в VS Code

1. **Визуальный diff.** Изменения в файлах подсвечиваются прямо в редакторе:
   зелёным — добавленные строки, красным — удалённые. Не нужно вручную
   сравнивать версии через `git diff`.

2. **Быстрый коммит через UI.** Можно выделить нужные файлы галочкой,
   ввести сообщение и нажать ✓ — не нужно переключаться в терминал.

3. **GitLens — визуальный git blame.** Прямо в редакторе видно, кто и когда
   написал каждую строку. Удобно для разбора legacy-кода и code review.

## 1 вещь, которую удобнее делать в терминале

**Сложные операции: rebase, cherry-pick, разрешение конфликтов при merge.**
В VS Code они спрятаны в меню или недоступны, а в терминале всё под контролем:
можно точно указать, какие коммиты объединить, как разрешить конфликт,
и видеть полный вывод команд. Также на сервере (по SSH) доступен только терминал.
